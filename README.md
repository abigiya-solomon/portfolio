# Abigiya Solomon — Developer Portfolio

A modern, responsive personal portfolio showcasing projects, experience, and skills in Software Engineering, AI, and Data Science.

🔗 **Live Site:** [https://portfolio-dusky-two-dw1dosxn0o.vercel.app/](https://portfolio-dusky-two-dw1dosxn0o.vercel.app/)

---

## 🚀 Overview

This portfolio is built to deliver a fast, clean, and thoughtful presentation of real-world software and machine learning projects. It combines fluid micro-interactions with accessibility and performance.

### Highlights & Features

- **Interactive Project Carousel:** Featured projects with 3D depth, smooth transitions, touch swiping, and **keyboard arrow navigation (`←` / `→`)**.
- **Deep-Dive Project Modals:** Detailed project overviews with architecture details, challenges, links to source code and live demos, plus expandable screenshot galleries (with keyboard navigation).
- **Downloadable Resume:** One-click direct download of the latest CV in PDF format.
- **Working Contact Form:** Connected via FormSubmit AJAX endpoint for direct inbox delivery, with instant validation, sending states, and mailto fallback.
- **Accessibility & Motion:** Built with semantic HTML, full keyboard navigation, ARIA live regions, and `prefers-reduced-motion` support.

## 💻 Getting Started Locally

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abigiya-solomon/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build locally:**
   ```bash
   npm run preview
   ```
